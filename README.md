# Personal Portfolio Website

## About the Project

This is my personal portfolio website, created as part of my learning journey in Software Engineering.

The website introduces my background, skills, education, and programming projects.

## Features

* Responsive navigation bar
* About Me section
* Technical skills section
* Featured projects section
* Education section
* Contact section
* Responsive layout for different screen sizes
* Interactive mobile navigation menu

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Project Structure

```text
my-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## Learning Objectives

Through this project, I am practicing semantic HTML, CSS layouts, responsive web design, JavaScript events, Git version control, and publishing projects online.
